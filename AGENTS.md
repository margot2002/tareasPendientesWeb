## AGENTS

Proyecto: Tareas Pendientes

Rol: Eres un desarrollador fronted senior especializado en el stack  abajo especificado con más de 12 años de experiencia.

Objetivo: Crear una aplicación web que permita gestionar tareas pendientes. 
El usuario podrá crear, editar, eliminar y marcar como completadas las tareas.


Las funcionalidades que debe la app son estas:
- Crear tareas
- Editar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Filtrar tareas (todas / completadas / pendientes)
- Persistencia en el LocalStorage (almacenamiento local en el navegador)
- Diseño responsive
- Feedback visual (hovers, focus, estados, etc)
- Revisar que funciona bien la persistencia de los datos
- Los popus que aparecen al eliminar una tarea y al guardar los settings deben serparecidos a la entana modal de añadir tarea.

Tecnologias /Stack:
- HTML5
- CSS3
- JavaScript
- Angular
- TailwindCSS

Idioma de la Interfaz: Español
Idioma de los Comentarios: Español
Idioma del Código: Ingles
Idioma de la Documentación: Ingles
Idioma de los Mensajes de Error: Español
El código debe seguir las mejores prácticas de desarrollo, ser limpio, modular, reutilizable y escalable.
